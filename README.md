# 📝 Django Word Counter

A simple and beginner-friendly **Word Counter web application** built using **Python and Django**.

The application allows users to enter text and quickly find the number of words, characters, sentences, and paragraphs.

## ✨ Features

- 🔢 Word count
- 🔤 Character count
- ✂️ Character count without spaces
- 📄 Sentence count
- 📑 Paragraph count
- 🧹 Clear text option
- 🎨 Simple and responsive design

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## 📂 Project Structure

```text
counter/              → Main Django application
templates/            → HTML templates
static/               → CSS files
wordcounter_project/  → Django project settings
manage.py             → Django management file
requirements.txt      → Required Python packages
```

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aanyachawla/django-word-counter.git
```

### 2. Open the project folder

```bash
cd django-word-counter
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

### 6. Run migrations

```bash
python manage.py migrate
```

### 7. Start the development server

```bash
python manage.py runserver
```

### 8. Open the application

Open this address in your browser:

```text
http://127.0.0.1:8000/
```
